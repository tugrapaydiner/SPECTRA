# Export-local structural index — experiment protocol, 2026-09-28

Base: PR36 afcf25a4d5ca222b44fedb0889d5d6a94ef05314. No production-runtime edits,
benchmark fitting, altered generated arithmetic or third-party submission.

Replace repeated recursive AST hashing with an export-local index whose interned
keys contain a node kind, normalized scalar fields and canonical child IDs. Identical
but separately allocated subexpressions must map to the same ID. Do not merge on a
hash alone. No permanent memoization across exports; AST must be quiescent during an
export. Unknown/custom/nonreflexive scalar semantics must explicitly reject indexing
and use the original structural cache for that entire cache epoch.

Compare the existing single-lookup/type guard with: a straightforward Python
bottom-up structural index, a native compact index, and its no-identity-memo variant.
The no-memo variant is a mechanism control, not a presumed faster reference. Retain
failed candidates and all end-to-end costs. Include an empty-cache-only control in
synthetic hashing probes where informative. Index construction and teardown are
included in full export measurements. Native extension builds are explicit; their
one-time time/size cost is reported separately.

Before formal measurement, check canonical IDs against original structural equality
on all supported kinds, structural-equal/distinct objects, ordered children, numeric
edge cases, deep graphs, hash collisions, cycles, memory limits, reference lifetimes,
cache reset and custom-node fallback. Outputs must match original generated source,
not just the previous candidate. Use the existing 19-model/16-language panel; keep
unsupported outcomes. Run unchanged upstream tests on a compatible environment when
available, without replacing original tests or stubbing optional dependencies.

Performance: seven unchanged frozen SVMs, all six small models in three fresh processes
per viable arm, larger HAR in at least one bounded screening attempt before the final
fixed replication. Same assembly+interpretation+cache teardown timer, excluding model
loading, imports and file write. Keep RSS, index resource counters, source/output hashes
and child time. Each child one CPU, one numerical thread, <=4 GiB address space, <=120s
wall. Clearly distinguish screening from final frozen measurements, and do not replace
slower final cells. Source and variants frozen before the final grid.

Primary useful-engineering gate: eliminate repeated descendant traversal in the
populated-same-type synthetic family while retaining equality and generated bytes;
end-to-end export must improve on the previous guard on expensive real models without
an unreported memory regression. Report small-model overhead, end-to-end versus
index-only complexity, all prior compiler failures, and missing original HAR reference.
This is hash-consing/structural indexing prior art, not newly invented theory or a
claim about learned intelligence, inference performance, adoption, or a hiring grade.
