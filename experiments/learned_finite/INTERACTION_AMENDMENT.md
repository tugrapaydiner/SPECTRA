# Pre-test interaction extension — September 28, 2026

The original experiment remains unchanged and fully retained. All six original kernel families and four external controls have been fitted/selected on development data for both tasks and all three splits. No model prediction or accuracy measurement has been made on either outer holdout.

Validation shows the NCA integer projection and radial mixtures do not beat the tuned isotropic RBF reliably. Learned weights can remove rare useful features. Record this negative development finding rather than promoting the primary. Add three separately labelled SECONDARY hypotheses before test opening:

1. Nonzero metric control: retain the same fixed learned weights, but replace zero projected values with one. Fit the same32 gamma/C candidates on the unchanged fitting subset; no further metric optimization.
2. Intersection-signature polynomial kernels: for binary features, P=sum(x_j*z_j) is an exact integer popcount. Kernel T[P]=(P/s+offset)^degree, where s is the fitting-set median positive pair intersection; degrees2/3/4/5, offsets0/1, and C0.1/1/10/100 give32 candidate slots. The validation-best polynomial is a separate model, not a replacement for a failed RBF primary. A nonnegative centered-alignment mixture of those eight polynomial tables receives four C choices; normalize the mixture consistently and serialize its exact table bytes.

Hamming spectral-table mixture: normalized Krawtchouk kernels for orders1/2/3/4/6/8/12/16 (orders exceeding feature width omitted), mixed by the same nonnegative centered-alignment rule with the eight original radial kernels. Four C choices. These kernels average same-order parity-feature inner products on the binary cube; no claim to invent them. Validate the recurrence and PSD property on complete small cubes before accepting the implementation. No strong performance prediction is made.

All extensions use the SAME development splits and existing learned weights. Every new selection and model is frozen before either test is opened. No selection among these families based on test outcomes, no refit, no new examples. Record additional fitting cost and candidate counts. The initial primary acceptance gate stays attached to metric_rbf only; secondary wins cannot relabel it as passed.

Original ordered coefficients, tie convention and independent replay remain. Extend loader bounds to signed finite table entries and bounded polynomial values; do not label all tables as RBF. No production model loader or runtime is changed. Further architecture changes after test opening would require a new experiment, not revision of this holdout.
