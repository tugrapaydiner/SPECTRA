## Main question and construction

Remove general-input abstention without a second external inference engine.
Preserve the exact existing16-bit certificate and add a lossless source leaf bank.
If certification is insufficient, reuse the already computed routes and perform
the original ordered binary64 sum, positive common scale and bias, with the same
first-class tie rule. This fallback does not return an exact-real sum: the original
floating-point operation order is the contract. Do not claim universal agreement
with optimized CatBoost backends that use a different reduction order.

Source leaves are stored as exact binary64 bit patterns. Compare flat storage with
canonical whole-vector interning (first occurrence, bitwise identity). No rounding,
pruning, dropped zero additions, dataset-aware dictionary or learned threshold.
Numerical verification reconstructs BOTH the compact proof and lossless payload
from the supplied source. Hashes bind identity, not mathematical validity by
 themselves. Only a source-verified object reaches the public native interface.

The new policy is total only for admitted bounded numeric oblivious-tree sources,
valid original uint8 inputs and the specified nearest-even/gradual-underflow/no-
contraction environment. Malformed/unsupported models, inputs or environments
fail explicitly; runtime errors are not converted to predictions. The existing
coarse/residual policies remain separately measurable abstaining controls.
