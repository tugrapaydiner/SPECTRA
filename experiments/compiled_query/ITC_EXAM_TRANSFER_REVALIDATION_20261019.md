# ITC exam-transfer timing amendment — 2026-10-19

The original transfer used one warmup and five measured repetitions.
That evidence, including the failed set9 development result and the
passing true holdouts, remains archived.

Revalidation uses eight warmups and 32 measured repetitions. The four
modes rotate through complete four-position blocks, so every mode
occupies every timing position equally. No selector rule, dataset,
query bank, expected mode, output, proof requirement, timing boundary,
or gate limit changes. The transfer evidence schema is bumped from v1
to v2 so amended evidence cannot be confused with the original run.
