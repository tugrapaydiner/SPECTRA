# Iteration 04: recorded scores must support recorded labels

Reviewed base: `b98929a4660b9af6c05c7d34f6871e1bb47b04ae`, the resource-audit
fix in PR #48. This changes recorded-data validation only. Native arithmetic,
learned models, original measurements and production defaults are unchanged.

## Reproduced defects

The auditor accepted NaN and infinite recorded scores when Python's `max()` still
selected the expected class. For stress records it checked hashes but neither
array dimensions nor whether the saved class indices followed from those scores.
Rehashing a shortened array or a contradictory index array therefore still passed.
Negative/Boolean coverage counts, incomplete stress coverage, out-of-domain input
bytes and changes to the declared stress settings were also accepted.

The new 21-case test set produced **20 failures and 1 positive pass** against the
base auditor. The positive control retains first-class ties, including signed zero.

## Change

The auditor now reads exactly the expected score/index payload plus one byte to
detect excess, validates finite binary64 scores and derives first-index argmax
labels for retained and stress records. Stress labels must agree with that
independent derivation as well as their recorded hash. Model layouts must report
consistent bounded geometry; stress bytes must fit the declared integer domain.

Coverage counts must be genuine nonnegative integers accounting for every row.
The replay lock must retain its existing 2,048 rows per stress kind and
`2026092961+d+D` seed rule. These values already appear in the source replay
script; no benchmark parameter or historical record is rewritten.

Counts overlap. The shared synthetic fixture now has the declared stress row

hashes to check that a hash match alone cannot hide a dimensional or label

so no fresh retained-corpus audit or rebenchmark is claimed.

This auditor checks recorded consistency; it does not rerun inference, authenticate
clocks or prove that scores were generated by a particular model. Native/source
equivalence remains a separate replay and reconstruction obligation.
