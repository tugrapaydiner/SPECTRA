# Iteration 1: bound legacy SVM iterator consumption

## Scope

Base: `58ae7cd79603a4ab32c4c08392a6ffa9a87a2976`, the reviewed head of PR46.
This is a maintenance fix stacked on that PR. No research branch is promoted,
and no classifier, native arithmetic, dataset, solver default or release changes.

The legacy sixteen-feature reader and the discrete certificate verifier used
`list(iterable)` before checking their known inventory sizes. Excess or endless
generators could consume unbounded time and storage before rejection. Both now
consume only the required inventory plus one item. Valid finite input keeps the
same ordering and conversion/voting semantics. This does not time-limit a single
iterator step or turn arbitrary Python iterators into untrusted safe code.

Eleven dependency-light regression cases include five that fail on the base
implementation. Guarded generators reproduce overconsumption without hanging the
test runner. Classes 2, 3, 16 and 128, exact/short/excess input, early geometry
rejection and ordinary valid iterators are covered.

## Reproduction and failed environment attempts

An initial public invocation found pytest absent. Dependencies were installed in
an isolated virtual environment. An initial full-suite invocation then produced
339 failures, 19 errors, 1,830 passes, 2 skips and 16 exclusions because the
default PyTorch extension cache was on a read-only filesystem. A diagnostic also
found the virtual environment's Ninja executable missing from `PATH`. The source
and tolerances were not changed to accommodate those failures. An affected
36-case group passed after correcting the environment, followed by the complete
passing fast run above.

From an activated environment with the declared CPU requirements and scikit-learn:

```bash
export TORCH_EXTENSIONS_DIR="$PWD/.review/torch-extensions"
export TORCHINDUCTOR_CACHE_DIR="$PWD/.review/torchinductor"
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 MAX_JOBS=1
python -m pytest -m 'not slow' -q
python -m build --no-isolation --outdir .review/reproduction/dist
python scripts/check_current_installation.py --dist .review/reproduction/dist --out .review/reproduction/installed-public
python scripts/check_svm_installation.py --wheel .review/reproduction/dist/spectra-0.7.1-py3-none-any.whl --out .review/reproduction/installed-svm
python scripts/audit_workspace.py --out .review/reproduction/history.json
python scripts/check_release_readiness.py
python scripts/render_readme_charts.py --check
```

The wheel filename reflects this unreleased source version. Existing release
bytes are not replaced. Use fresh output paths on subsequent attempts.
