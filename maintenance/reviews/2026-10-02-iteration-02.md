# Iteration 02: complete total-tree kit verification

Reviewed base: `7012142d2ca37529a5b2c176c15cd989316b2846`
(`research/total-tree-execution`, PR #45). This follow-up stays on the experimental
tree branch. It changes no production default, model, native arithmetic, retained
benchmark observation or accuracy claim.

## Reproduced problem

`verify()` checked only the files a manifest happened to list. An empty `models`
and `files` inventory was accepted. In an isolated `python -I -S` subprocess,
`selftest_main()` then wrote `status: PASS`, zero rows and no model records without
loading or verifying any model. Removing an executable/model from both disk and
the manifest also bypassed completeness checking; unlisted files were ignored.

The initial 27-case regression set produced **23 failures and 4 passes** before
the fix. These included the observed empty-kit false success, missing assets,
unlisted files, invalid model metadata, duplicate fields, oversized manifests and
a symlinked manifest. This is an integrity/completeness defect, not a claim that
SHA-256 authenticates an author or makes hostile executable code trustworthy.

## Change

- Share the required source/model/native inventory between assembly and checking.
- Require all four named models, all 44 payload files, and exact agreement between
  the declared inventory and regular files on disk. Reject symlinks and malformed
  or noncanonical member paths.
- Bound manifest reads to 1 MiB, reject duplicate JSON fields and nonfinite numbers,
  and validate integer replay bounds, class mappings, sizes and SHA-256 metadata.
- Check replay input/output dimensions and source metadata before replay. Hash
  payloads incrementally instead of reading each entire payload into memory.
- Require self-test reports to be new files outside the immutable kit, matching
  the existing prediction runner's output-location policy.
- Include kit tests in both CI test commands and enable this workflow for pull
  requests targeting the total-tree research branch.

The format identifier is unchanged. The verifier still accepts additional files
when the manifest binds them, but cannot omit a required file. Source reconstruction
remains the numerical proof; file verification remains a trusted byte inventory.
Concurrent mutation of a kit during verification/use is outside the contract.

## Observed validation

Environment: Linux x86-64, CPython 3.12.14, pytest 9.0.2, GCC 13.3.0.

| Check | Observed result |
| --- | --- |
| Unmodified tree source/deployment contracts | 122 passed, 4.69 s |
| Initial focused regressions against unmodified kit | 23 failed, 4 passed |
| Final portable tree suite, including 37 kit cases | 159 passed, 10.48 s |
| Same suite with the shared runtime fixture using AVX2 + UBSan | 159 passed, 6.93 s |
| Synthetic complete-kit assembly and isolated replay | Portable and AVX2 both passed; 4 fixtures, 16 rows, 48 policy predictions per target |
| Synthetic isolated JSONL runner | Expected indices `[0, 1, 0, 1]`, complete footer, bundle unchanged |
| Existing workspace preservation audit | 449 historical files and recovered helper byte-identical; 58 guide links valid |
| `git diff --check` | Passed |

The kit integration test explicitly builds its own ordinary portable and AVX2
libraries; the UBSan override applies to the existing source/deployment runtime
fixture. The synthetic fixture is not the retained four-dataset benchmark.

During test development, an initial invocation omitted `--import-mode=importlib`
and failed collection. One new assertion initially treated the JSONL header as a
prediction; it was corrected to inspect prediction records and the completion
footer. Neither failure was a numerical disagreement. Local chronological logs
are retained under `.review/01-baseline` and `.review/02-kit`; these are not committed
benchmark evidence.

Reproduce the final test gates:

```bash
python -m pytest experiments/tree_total --import-mode=importlib \
  --confcutdir=experiments/tree_total -q
python -m experiments.tree_total.build --out /new/total-ubsan --target avx2 --ubsan
TOTAL_LIBRARY=/new/total-ubsan/total.so python -m pytest experiments/tree_total \
  --import-mode=importlib --confcutdir=experiments/tree_total -q
python scripts/audit_workspace.py --out /new/workspace-audit.json
```

No retained-corpus rebenchmark, Windows/ARM acceptance, production release or
prediction-quality improvement is asserted by this iteration.
