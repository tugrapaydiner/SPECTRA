# Historical documents and workflows

These files are intentionally retired from the active working tree, not lost.
Every link below points to the full pre-cleanup commit
`181e236528b5b58263c98b09925f0d7612c919d3`. Original Git blob IDs and SHA256 values
are in [the retention receipt](../../maintenance/relocations.json).
Use an isolated historical checkout to rerun a retired launch workflow. Do not
copy its old checkpoint or scientific claims into the current default.

```bash
git worktree add --detach ../spectra-history 181e236528b5b58263c98b09925f0d7612c919d3
```

## Active workflows and coverage

`cpu-regression.yml` is the canonical two-version fast regression and retained
research replay. `native-contract.yml` keeps native differential/build/scalar
checks; `task-data-contract.yml` keeps task contracts and split-manifest checks.
Their duplicate full-suite invocations are removed. The earlier M01 energy API
and optimizer checks live in the CPU workflow. Current SAT, cache, symmetry and
public-package workflows remain separate. The main-only archival workflow is
maintenance, not a scientific acceptance gate.
