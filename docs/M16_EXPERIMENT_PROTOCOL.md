## C: evaluator-target development, not confirmation
On the fixed new training split, create a common pool with four identity-spine depths and four actions per depth (identity plus three fixed random normalized latent directions, scale 0.5, direction seed 16111). Compare selectors on identical development pools first: legacy improvement, learned terminal probability, learned structural quality, and exact first-valid selection. Then run checked best-first closed-loop search (not mislabeled MCTS) with max depth 4, a charged four-step identity prefix and 24 total transitions, on the same development puzzles. This two-core-seed 4x4 development study cannot establish cross-task generalization.
