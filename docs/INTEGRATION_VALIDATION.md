## 2. Stored evidence and independent semantic checking

```bash
python scripts/verify_retained_results.py --out outputs/retained-audit.json
```

This verifies exact archive inventories and ancestral exclusions, checks 1,728
manifest rows against input/target fingerprints, independently validates 11,520

## 3. Actual trained-checkpoint inference replay

```bash
python scripts/verify_checkpoint_replay.py --out outputs/checkpoint-replay
```

This loads the exact accepted source cores and fitted value checkpoints, reuses
only the retained development inputs, executes every recorded solver arm once
per model-example pair, and compares current answers, validity and work counts
against the original rows. It covers 3,840 distinct model-example-arm comparisons
across two task families and four trained cores. This is different from merely
rechecking stored answers or counting unit tests.

The first local hardened-search replay passed all 3,840 comparisons with no answer,
validity or transition/decode/value-work mismatch. The portable CLI is also run in
CPU CI on Python 3.11 and 3.13. The replay records executable-source hashes and
refuses partial coverage or source changes during the run. Failures are retained
and cause a nonzero exit. Output locations must not already exist.

Inputs default to the durable tracked M14/M15 source ZIPs and accepted M16/M17
canonical archives. Optional path overrides change storage location, not expected
content identities. There is no model training, new task generation, confirmation
reopening, or performance-improvement claim in this replay.

## Scope boundary

Fast tests and checkpoint replay do not imply that every legacy long-running
training/capability gate has passed. `python -m pytest -ra` exercises that separate
scope. No assertion or acceptance threshold is weakened here to label a negative
training or scientific outcome as successful. The PR's exact-head CI results,
not a successful ancestor alone, govern the integration decision.

Copying state is charged real work. Historical M17 timing numbers remain attached
to the historical executable source; this correctness replay does not transfer
those speed claims to the hardened copying path.
