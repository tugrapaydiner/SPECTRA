# Exact cached CNF residuals: bounded systems protocol

Base: main e73dc05379b38ab2689e0e3054f6eee74e0290c0. PR23's negative learned repair experiment remains draft and is not promoted by this work.

Hypothesis: maintaining exact single-variable make/break counts incrementally reduces the full execution cost of an unchanged focused local-search policy. This is an optional classical research primitive, not a learned capability or originality claim. Historical runtime defaults, checkpoints, scientific thresholds and evidence remain unchanged.

Inputs: 64 unfiltered generated CNF formulas: uniform and planted random 3-SAT, 64/128/256/512 variables, eight formulas per family/size cell. Clause count floor(4.2*n). Formula seeds start at 620260911, with one seed per case in family/size/index order. Both families use the existing data.cnf generator without filtering on solver outcomes. Planting witnesses are not passed to the search. Search seeds are 17001 and 27002; three timing rounds; 1,024 maximum single-variable flips; no restarts. Every formula and observation must be retained.

Both arms execute the same Python focused probSAT-style policy, not the authors' optimized probSAT implementation: select a uniformly random violated clause, choose its distinct variables with weights (1+break)^(-2.3), and apply one flip. Input and RNG conventions, tie ordering and selection arithmetic are identical. Only the residual state class differs: historical CNFRepairState versus the new optional cached state. Uniform and planted formulas may remain unresolved; lack of a witness is UNKNOWN, never UNSAT. Both arms stop on exact validity or the flip cap. A complete final original-formula check is mandatory for every observation, including failures.

Warm full-execution timing includes assignment generation, state construction, all score queries and flips, witness materialization, original-formula checking and explicit state release. Parsed formula generation, source hashing, output serialization and the immutable weight-table construction are outside. One separate warm-up formula is not included in evidence; no observation from a declared input is discarded. Alternate arm order by case/search-seed/round parity. Record all raw durations, final assignments, path hashes, statuses, move counts and actual work counters. This is a capped full search execution, not a guaranteed complete SAT decision procedure or a hard wall-clock budget experiment.

Correctness gate: every paired fixed-work trajectory hash, final assignment, flip count and status agrees. Strict inventory validation rejects duplicates, missing records, changed inputs and invalid time/work values. Independent answer and score tests include empty clauses, zero/unused variables, repeated literals, tautologies, arbitrary clause lengths and atomic multi-variable flips. All prior fast regression and retained-evidence audits must pass; slow retraining is reported separately.

Performance gate (frozen before measurements): bootstrap complete formula clusters after collapsing search-seed and timing repetitions. Overall mean-time ratio's descriptive paired 95% upper endpoint must be <=0.80; each family/size cell upper endpoint <=1.10; overall p95 point ratio <=1.00. Candidate/reference ratios below one favor caching. Use 4,000 bootstrap replicates with seed 90260911. Report all strata and every failed condition. This bounded systems gate does not certify cross-machine speed, modern external SAT superiority, learned reasoning, physical energy or an employment level. Timing replays are reproduction, not independent confirmation.

Publication: preserve source identities, raw inputs/observations, analysis and failure logs. Merge only the optional primitive and its verified systems evidence if the gate passes; never merge PR23's failed learner as a capability promotion. Implementation publication following local correctness development is not external preregistration.
